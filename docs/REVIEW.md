# 提交前复查与改进

## 真实问题：固定模型的输入契约未校验

复查时直接调用切块方法，发现原实现仅依据元素总数重排：

```python
encoder.patchify(np.zeros((1, 3, 112, 448), dtype=np.float32))
```

原先会返回 `(1,49,3072)`，没有提示图像尺寸错误。NHWC 格式和标准 CHW 格式的元素总数同样相等，也会被误解释。float64 输入还会沿后续计算传播，最终不符合老师的 float32 要求。

修复后，`ImageEncoder.patchify` 在重排前验证：

1. 输入是 NumPy 数组，否则抛出 `TypeError`。
2. 输入为四维且后三维严格等于 `(3,224,224)`，否则抛出 `ValueError`。
3. 数组类型为 float32，否则抛出 `TypeError`，提示使用课程预处理。

新增三个回归测试覆盖错误图像尺寸、NHWC、缺少 batch 轴、float64、uint8 和列表输入。与原有三个测试一起，六个测试全部通过。
